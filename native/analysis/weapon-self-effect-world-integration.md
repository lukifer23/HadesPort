# Source weapon self-effect storage

Add `self_effect_world.cpp` to the native target and retain the existing `self_effects.cpp`, `effect_affect.cpp`, `speed_effects.cpp`, `effect_update.cpp`, and `unit_status.cpp` implementations. Construct `WeaponSelfEffectWorld` with the real `ActorWorld`; it must die before that world or its source catalogs reset. No new asset packet is needed beyond player-weapons-v13.

Weapon `ApplySelfEffects` output calls `applyWeaponEffects(ownerId, weaponName, trigger, providers, admissionResult, error)` synchronously. Charging is trigger3; Fire is1. `CancelWeaponSelfEffects` calls `cancelWeaponEffects`. Projectile Init calls `clearOnAttack`. Do not advance the execution cursor until the operation succeeds. Errors preserve partial native operations/RNG and permanently fault the effect world, preventing replay as a new transaction.

At the actual UnitStatus phase, after preceding native timer/allegiance work, call `updateUnit(owner, unitElapsed, providers, error)` exactly once. It uses the owner's real pending/active/toDelete vectors and updates live speed fields. It does not advance other Unit phases. Reflection mutations of existing per-weapon effects require `refreshUnit` before owner CanAttack/CanMove queries.

Provide actual stream0 RNG. `affect` receives the exact operation, real instance, owner DTO, live source EffectData and reapplied flag. Implement original Lua OnEffectApply and Unit.OnStun there, including actual source weapon requests. The component already commits elapsed-time changes before these barriers and speed math after the native base AffectUnit callback. Original callbacks can mutate copied source data. Missing operations must return errors, never true as an acknowledgment.

`onCleared` runs the original source-filtered OnEffectCleared dispatcher. `instance.state` supplies concrete NumStacks, applied multiplier and retained FX/sound handles. The provided source record supplies actual Type/Name/Modifier/Duration/etc. OnEffectCleared fields are EffectType, EffectName, Exists(World Thing ID lookup), IsVulnerabilityEffect, ElapsedTimeMultiplier; common Script.run supplies owner context. Public REA evidence is retained in the JSON contract.

The first Sword Speed/Tag defaults use internal base Clear/Reapply state transitions and mandatory original callbacks. Nondefault FX/audio/property Clear/Reapply branches remain explicit provider barriers. `hasRefreshOnExpireEffect` is now optional: the world performs real native-ID HasEffect lookup internally, including ToDelete masking. Header IDs retain omitted constructor0 vs explicitly-read XXH3 strings; exact matching 2020 short-name algorithm is translated directly without an installed xxhash dependency. Unsupported effect factories and Tag Rate>0 fail at admission.

Snapshots include live state plus at most64 disposed diagnostic records. Disposal releases live storage once real status references are gone; stale effect lifetime handles do not alias a recycled object. This is a documented portable allocation choice, not Windows pointer emulation. Standalone ASAN debug uses original catalog data with recorded callback barriers and does not claim original Lua execution or gameplay.
